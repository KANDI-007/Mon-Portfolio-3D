# Portfolio 3D - Kandi Salman LARE

Portfolio personnel moderne avec animations 3D, développé avec React, TypeScript, Vite, Three.js et Framer Motion.

## 🚀 Technologies

- **React 18** - Bibliothèque UI
- **TypeScript** - Typage statique
- **Vite** - Build tool rapide
- **Three.js** - Rendu 3D
- **Framer Motion** - Animations fluides
- **Tailwind CSS** - Styling
- **Lucide React** - Icônes

## 📦 Installation

```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Build pour la production
npm run build

# Prévisualiser le build
npm run preview
```

## 🌐 Déploiement sur Netlify

### Méthode 1 : Via GitHub (Recommandé)

1. **Pousser le code sur GitHub :**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/KANDI-007/Mon-Portfolio-3D.git
   git branch -M main
   git push -u origin main
   ```

2. **Connecter à Netlify :**
   - Aller sur [netlify.com](https://www.netlify.com)
   - Cliquer sur "New site from Git"
   - Sélectionner GitHub et autoriser l'accès
   - Choisir le repository `Mon-Portfolio-3D`
   - Les paramètres de build sont automatiquement détectés :
     - Build command: `npm run build`
     - Publish directory: `dist`
   - Cliquer sur "Deploy site"

### Méthode 2 : Via Netlify CLI

```bash
# Installer Netlify CLI
npm install -g netlify-cli

# Se connecter
netlify login

# Déployer
netlify deploy --prod
```
